# /n

This is /n (backslash-n), the legendary demo from the golden days of BeOS (the year 2000, to be precise). Now ported to Haiku and RenkuOS.

[![backslashn.png](https://i.postimg.cc/T3WZWjgY/backslashn.png)](https://postimg.cc/dhwWby5z)

I remember it as a fullscreen demo rather than just in this little window, but it remains a nostalgia trip. And just like the original, it doesn't die willingly - you may have to use Process Controller or Slayer to get rid of it. No, I'm not going to fix that. It's part of its charm.

To compile under Haiku, open a Terminal in the directory where you saved this, then

```
mkdir build && cd build && cmake .. && make

```
